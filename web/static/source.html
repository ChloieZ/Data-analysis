上传花销表格 支持 Excel / CSV / TXT，上传后自动导入并重跑 ETL

← 也可以把 .csv / .xlsx / .txt 文件直接拖到这块虚线区域

支持格式：.xlsx / .xls / .csv / .txt； 首行须为表头，至少包含 日期、类别、金额 三列（备注 可选）， 列名支持 date / category / amount / note 等英文别名。
数据形状：每行一笔（长表）直接入库；宽表（「日期 + 餐饮 / 交通 / 房租… 各占一列」，原始 Excel 常见） 与多 Sheet 的 Excel 会自动转换成长表，无需手动处理。
TXT / CSV：自动识别 UTF-8 / GBK 编码，自动识别分隔符（逗号、分号、制表符、竖线、空格）。
入库规则：追加模式按「日期+类别+金额+备注」判重（重复跳过）；替换模式会先删除文件中出现月份的旧数据。

SQL 追加 用 SQL 语句直接追加数据，随后自动重跑 ETL

① 查询写法：结果集需含 日期、类别、金额（备注 可选）， 列名支持 date / category / amount / note 别名 → 按上面勾选的规则去重后追加； ② 写入写法：INSERT / UPDATE 等直接执行，去重由语句自己负责。 建议写入 raw_spending —— ETL 会基于它重建明细层与汇总层（只支持单条语句）。
