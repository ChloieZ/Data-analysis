# 指标口径说明

本文件定义平台的核心指标口径，保证「同一指标、任意入口、多次查询结果一致」。

## 1. 通用口径约定

| 约定 | 说明 |
| --- | --- |
| 有效记录 | 金额 > 0 且日期可解析为标准日期的记录 |
| 退款处理 | 退款若以负数记录，**当前版本不计入支出**（会被 ETL 过滤），后续可扩展为单独指标 |
| 月份口径 | 按**自然月**，格式 `YYYY-MM`，不按滚动 30 天 |
| 金额精度 | 存储为 DOUBLE，展示与汇总保留 2 位小数 |
| 类别口径 | 去首尾空格并统一为大写后的类别值 |
| 数据来源 | 汇总类指标优先命中汇总表 `dws_monthly_category`，明细类查询走 `dwd_spending` |

## 2. 核心指标

| 指标名 | 口径 | 计算逻辑（SQL） | 单位 |
| --- | --- | --- | --- |
| 月总支出 | 当月所有有效记录金额之和 | `SUM(amount) WHERE month = ?` | 元 |
| 分类支出 | 当月某类别金额之和 | `SUM(amount) GROUP BY category` | 元 |
| 分类占比 | 分类支出 / 月总支出 | `分类支出 / 月总支出 × 100%` | % |
| 环比变化 | 本月总支出 − 上月总支出 | `本月月总支出 − 上月月总支出` | 元 |
| 笔均支出 | 月总支出 / 当月记录数 | `SUM(amount) / COUNT(*)` | 元 |

> 实现位置：`src/spend_analytics/metrics.py`（指标字典 `METRIC_CATALOG` 与各函数）。

## 3. ETL 清洗规则

原始层 `raw_spending` 的全部字段均为字符串，ETL 时按下表转换：

| 字段 | 规则 |
| --- | --- |
| 日期 | 依次尝试 `%Y-%m-%d`、`%Y/%m/%d`、`%Y.%m.%d`、`%Y%m%d`、`%Y年%m月%d日`、带时间戳格式，转为标准 `DATE`；全部失败则丢弃该行 |
| 月份 | 由标准日期派生 `strftime(date, '%Y-%m')` |
| 类别 | `UPPER(TRIM(类别))`，为空则丢弃 |
| 金额 | 去除货币符号、千分位、空格后转 `DOUBLE`；为空或 ≤ 0 则丢弃 |
| 备注 | `TRIM(备注)` |

被丢弃的行会在 ETL 统计中分类计数（非法日期 / 非法金额 / 非正金额 / 空类别），便于质量监控。

## 4. 数据分层

```
Excel/CSV
   │  数据接入（去重：日期+类别+金额+备注）
   ▼
raw_spending      原始层（全 VARCHAR）
   │  ETL：清洗、转换
   ▼
dwd_spending      明细层（逐笔有效记录）
   │  ETL：聚合
   ▼
dws_monthly_category  汇总层（月 × 类别：总支出、笔数）
   │
   ▼
Web 自助分析 / Metabase
```
