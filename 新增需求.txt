数据分析平台功能规划（V1.0）

本平台旨在提供从数据接入、数据管理到可视化分析的一站式轻量级 BI 服务，共规划三个核心页面：

1. 首页（数据大屏 / Dashboard）

核心指标概览：展示总支出、月度支出等关键 KPI 卡片。

全局筛选：支持按时间范围（年/月/自定义）筛选，联动全屏图表。

多维度图表：结合折线图、饼图、柱状图，展示支出趋势、类目占比及明细分布。

2. 数据展示页（数据管理 / Data Management）

数据表格：以分页表格形式展示数据库中的数据，支持排序和字段筛选。

Excel 上传：支持用户上传 .xlsx 文件，后台进行格式校验（日期、金额等），校验通过后自动入库 PostgreSQL（支持追加/覆盖模式）。

SQL 查询器：提供一个安全的 SQL 查询窗口，仅允许执行 SELECT 语句，支持查询结果导出。

3. 图表制作页（可视化分析 / Chart Builder）

数据源选择：用户可选择已导入的数据表作为分析源。

拖拽式分析：提供维度（Dimensions）、度量（Measures）和筛选器（Filters）区域，用户通过拖拽字段完成配置。

SQL 自动生成：后台根据拖拽逻辑和图表类型（折线图、柱状图、饼图等），自动生成聚合 SQL 语句并查询数据。

实时预览与保存：图表实时渲染预览，支持将配置保存为“我的图表”以便后续复用。
